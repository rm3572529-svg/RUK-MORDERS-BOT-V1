# RUK MORDERS BOT V1

Telegram file-sharing bot with admin panel, built with Python / aiogram-style architecture.

## Setup
1. Copy `.env.example` to `.env` and fill in your own values (bot token, database URL, etc.).
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python -m app.main` (or use the provided Dockerfile / render.yaml).

See `README.md` inside the project for full details.
